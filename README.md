## 📖 项目简介

本仓库系统整理了 PTA 基础编程题目集的 **JavaScript 语言** 题解，适合：

- 正在学习 **JavaScript（Node.js）** 的初学者，对照 PTA 题目边练边学
- 已熟悉 C/Python 的同学，快速了解 JavaScript 在 **输入处理、字符串、数组、数值计算** 上的写法差异
- 需要 **PTA 作业/考试** 参考的同学，代码均按题目输入输出格式严格实现

每篇题解均包含：

- **前言** — 考点与易错点一句话概括
- **题目描述 / 输入输出格式 / 样例**
- **解题思路** — 分步骤讲清关键推导
- **完整代码** — `javascript` 代码块，可直接 `node` 运行，附详细注释

> 代码风格统一：`fs.readFileSync(0, 'utf8')` / `readline` 处理输入，工具函数单职责，`main` 只做 IO 与调用。
